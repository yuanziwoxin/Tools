## 1 概览

### 1.1 能力全景

从「已经写下的文字」到「能交付的文档」，中间要走的路它都铺好了：

<p align="center">
  <img src="feature-map.svg" width="920" alt="能力全景：输入 → 编辑与整理 → 12 种输出，底层是三层数据安全"/>
</p>

一句话版本的判断标准：**你要做的事，是不是「把一堆文字变成有结构的东西，再交出去」**。如果是，这个工具从头到尾都能接住。

### 1.2 功能清单

**输入 —— 把已有文字变成结构**

- Markdown / 纯文本大纲 / XMind / OPML / 本工具 JSON 都能进；Word、PDF 复制粘贴即可
- 导入预览就是一棵**可勾选的条目树**，不想要的先划掉，生成前就知道会得到什么
- 竖排的**箭头流程**（`A ↓ B ↓ C`）自动去掉箭头，可选串成链
- 选中节点后 `Ctrl+V` 贴一段文字，直接在该节点下生成子树

**编辑 —— 改结构不用删了重加**

- 拖住节点放到另一个节点上，整棵子树改挂（带环路检查）
- `Tab` 加子节点、`Enter` 加同级、`F2` 改名、方向键走树、`Alt+↑↓` 调顺序，全程不摸鼠标
- 多选批量删除 / 上色 / 折叠 / 贴标记；框选一批一起处理
- 批量文本清洗：加前后缀、去行首编号、全半角转换、按分隔符拆分、多节点合并
- 可读名的撤销历史，点一行直接跳回去

**附加信息 —— 备注、标记、链接**

- 任意节点可加多行备注、贴语义标记（⭐❗❓✅🔒）、挂网页地址或本机路径
- 三种附加信息在 12 种导出里都有对应落点，不会导出一次就丢

**查找与整理 —— 图大了也找得到**

- `Ctrl+F` 搜索（含备注、区分大小写、全词、正则）＋ 批量替换
- 左侧大纲视图：点行定位、双击改名、拖动排序或改挂
- 右下角缩略图导航
- 结构统计：层级分布、分支占比、标记汇总、上次渲染耗时

**视图 —— 一份数据，多种看法**

- 左右（思维导图）/ 上下（组织结构图）双布局，切换不改数据
- 沉浸全屏（工具栏一并隐藏）
- 6 种字体 × 4 档字号 × 3 种字重 × 5 档节点宽度 × 9 套主题 × 8 套配色 × 4 种底纹

**输出与保存 —— 交得出去、留得下来**

- 12 种导出格式（图片 / Office / 数据互通），备注与链接都跟着走
- 三层数据保险：浏览器本地存档 + 历史快照 + 自动备份目录
- 工作区最多 24 个页签，可整包搬去另一台电脑

## 2 开始使用

### 2.1 打开文件与欢迎页

1. 把 `mind_map.html` 放到一个固定的文件夹（别留在下载目录，方便长期找）。
2. **双击打开**，或者在浏览器里 `Ctrl+O` 选择这个文件。
3. 首次打开是欢迎页，四条路任选：

| 入口 | 适合场景 |
| --- | --- |
| **从文档生成** | 已有笔记、大纲、会议纪要、Markdown 文档，想快速变成导图 |
| **空白白板** | 从零开始整理思路，边想边写 |
| **打开已有导图** | 继续编辑之前保存的 `.json`，或打开 XMind 的 `.xmind`、OPML 大纲 |
| **从模板开始** | 不知道怎么搭结构？读书笔记 / 会议纪要 / 项目计划一键起手 |

<p align="center">
  <img src="../screenshots/mindmap-welcome.png" width="720" alt="首次打开的欢迎页：从文档生成 / 空白白板 / 打开已有导图 / 从模板开始"/>
</p>

推荐浏览器：Edge / Chrome / Firefox / Safari 的较新版本。

### 2.2 从文档生成

这是最常用的入口。点顶部 **「导入文档」**，或直接把文件拖进窗口。

**支持的输入**

- 文件：`.md` `.markdown` `.txt` `.json`（本工具导出）`.xmind`（XMind 导出）`.opml`（XMind / 幕布 / Workflowy / 飞书导出的大纲）
- 直接粘贴：Word / PDF / 网页里的文字复制进粘贴框即可（这两种格式无法直接读文件，复制粘贴更快）

**能识别的结构**

- Markdown 标题：`#` `##` `###` …
- 编号大纲：`1.` `1.1` `1.1.1`、`一、` `（一）`、`第 X 章`
- 缩进与无序列表：`-` `*` `•`
- **箭头流程**：竖着写的 `A` / `↓` / `B` / `↓` / `C`（详见 [2.2.1](#221-箭头流程)）
- **表格**：`| a | b |` 形式，首列当节点、其余列当子节点（「列名：值」）

**生成选项**

| 选项 | 说明 |
| --- | --- |
| 根节点 | 留空则用文件名当中心主题 |
| 最多保留 | 默认 4 层；长文档建议先设 2~3 层，避免导图被细节撑爆 |
| 保留原文编号 | 默认勾选，保留 `1.1` 这类编号 |
| 收录列表项 | 默认**不勾**（只取标题）。正文细节多时可勾选，但节点会暴涨 |
| ↓ 串成流程链 | 默认**不勾**（＝只删箭头、各步骤平级）。勾上＝把 `B` 挂成 `A` 的子节点。**这个选择会被记住**，粘贴路径也跟着它走 |

生成后会替换当前画布内容，`Ctrl+Z` 可以整棵撤回。

**预览就是可勾选的条目树**：每个条目左边有勾选框，不想要的直接取消勾选（它下面整棵一起划掉并置灰），底部写着「已划掉 N 个」，生成按钮的可用状态与实际会生成的节点数同步；角落还有「全选 / 全不选」。中心主题那一行不给取消。换一份输入，勾选状态自动重置。

**只想给某个节点补充内容？** 选中它后直接 `Ctrl+V` 粘贴一段文字，就会**在它下面生成子树**（不用整张替换）。识别结构同上，「名称：说明」这种行会自动拆成两层（名称当节点、说明当子节点）；生成后 `Ctrl+Z` 可撤销。

> **备注能往返**：本工具导出的 Markdown 会把备注写成 `> 备注：…` 引用块，**重新导入时能读回节点上** —— 「导出 .md → 改一改 → 再导入」这条路，备注不会丢。

#### 2.2.1 箭头流程

流程图、Agent 执行链路、流水线步骤最常见的就是一列文字：

    默认（不勾）                      勾选「↓ 串成流程链」后
    User                            User
    ↓                               └─ LLM
    LLM                                └─ Tool Call
    ↓                                   └─ Tool
    Tool Call                              └─ Tool Result
    ↓                                         └─ LLM
    Tool                                           └─ Final Answer
    ↓
    Tool Result
    ↓
    LLM
    ↓
    Final Answer

- **箭头行自动去掉**：`↓ ⇓ ⬇ → ⇒ ➜ ➡ ⟶` 和 ASCII 的 `->` `-->` `=>` `==>`，`↓↓↓` 这种重复的也算一个；`- ↓`、`1. ↓` 带标记的同样算。整行只剩箭头才算 —— 行内的「温度 ↓」「A → B」是节点名字，不拆。
- **默认平级**：箭头删掉后，各步骤是平级的兄弟节点。
- **勾选才串成链**：勾上「↓ 串成流程链」后，一个箭头把它后面第一个步骤挂成前面那个的子节点。
- **粘性偏好**：在导入面板勾一次就会记住，之后**粘贴**也按它走（默认平级）。
- **标题不让箭头推翻**：`# A ↓ # B` 仍是两个平级标题（`#` 的个数说了算）。
- 表格 / 代码块 / 备注里的箭头全程不受影响。

### 2.3 从模板开始

不知道结构该怎么搭的时候，直接套一套现成的骨架：顶部 **「📐 模板」**（欢迎页也有「从模板开始」入口）。

| 模板 | 内容 |
| --- | --- |
| **空白白板** | 只留一个「中心主题」，完全自己搭 |
| **读书笔记** | 基本信息 / 核心观点 / 章节脉络 / 精彩摘录 / 我的思考 / 行动清单 |
| **会议纪要** | 会议信息 / 议题 / 结论与决议 / 待办事项 / 待确认问题 |
| **项目计划** | 背景与目标 / 范围 / 里程碑 / 分工 / 风险与对策 / 交付物 |

每张卡片带着图标、说明和**骨架前两层的预览**，选之前就知道会长成什么样。点一下即生成：

- 画布上已有内容时会先弹确认框（并给「一键备份」入口），不会默默覆盖你的东西；
- 整套生成只压**一个撤销点**，`Ctrl+Z` 一次就能撤回；
- 生成后会顺手把「只看 N 层」复位到「全部」、清掉残留的搜索筛选，保证新骨架完整可见。

### 2.4 打开已有导图

点顶部 **「打开」**，或把文件直接拖进窗口：

| 文件类型 | 打开后 |
| --- | --- |
| `.json`（本工具导出） | 完整回来：节点、备注、标记、链接、折叠状态、外观偏好 |
| `.xmind` | 读成可编辑的树（备注能读回） |
| `.opml` | 大纲读成树（`_note` 里的备注能读回） |
| `.html`（独立网页） | 用浏览器打开它本身就是工具；要合并进当前画布请用它的「导出 .json」再导入 |

画布上已有内容时，替换前会弹确认框，并直接给三个按钮：**备份 .json 并继续**、**备份网页并继续**、**不备份，直接继续**。

## 3 编辑内容

### 3.1 节点基本操作

先单击选中一个节点（选中的节点会高亮），然后：

| 想做什么 | 工具栏按钮 | 快捷键 | 说明 |
| --- | --- | --- | --- |
| 新增子节点 | 子节点＋ | `Tab` | 在当前节点下面加一层 |
| 新增同级 | 同级＋ | `Enter` | 和当前节点平级 |
| 编辑文字 | 编辑 / 双击节点 | `F2` | 编辑中 `Enter` 保存、`Esc` 取消 |
| 上移 / 下移 | ↑ ↓ | `Alt+↑` `Alt+↓` | 在同级里调整顺序 |
| 删除该节点 | 删节点 | `Delete` | 连带子节点一起删（先确认；根节点不能删，只能改名或清子节点） |
| 删除所有子节点 | 删子节点 | `Shift+Delete` | 先确认，**保留**自己，只清掉下面所有层 |
| 移动整棵子树 | — | 按住左键拖动 | 拖到另一个节点上松手，整棵挂过去（见 [3.4](#34-拖拽改挂)） |
| 撤销 | 撤销 | `Ctrl+Z` | 删除、生成、清空、拖拽改挂都能撤回 |
| 重做 | 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` | 撤销多了走回来；一旦有新改动，旧的重做历史作废 |
| 复制子树 | 右键菜单 | `Ctrl+C` | 连同下级整棵复制（同时写入系统剪贴板） |
| 粘贴子树 / 粘贴文字 | 右键菜单 | `Ctrl+V` | **自动判断**：剪贴板是刚复制的子树 → 照常粘贴；是一段文字 → 解析成子树挂在选中节点下 |
| 原地克隆 | 右键菜单 | `Ctrl+D` | 在同级后面复制一份（含整棵子树） |
| 键盘走树 | — | `↑↓←→` | `↑↓` 在同层上下（含表亲节点，到头绕回另一头）、`←` 回父节点、`→` 进第一个子节点；`Home / End` 跳到同层首末 |
| 折叠 / 展开 | 节点右侧 ＋/− | `空格` | 对选中节点切换折叠（多选时对整批生效） |
| 写备注 | 右键「编辑备注」 | `Ctrl+Shift+M` | 见 [3.6](#36-节点备注) |
| 语义标记 | 右键「标记」 | — | 见 [3.7](#37-语义标记) |
| 节点链接 | 右键「编辑链接」 | `Ctrl+Shift+L` | 见 [3.8](#38-节点链接) |
| 复制为文本 / Markdown | 右键菜单 | `Ctrl+Shift+C` | 按缩进（纯文本）或 `#` 标题层级（Markdown）写进剪贴板 |
| 单节点高亮 | 右键菜单 🎨 | — | 给选中节点及其全部下级上色（边框、底色、连线一起变） |
| 右键菜单 | — | 鼠标右键 | 上面这些操作右键也都在 |

### 3.2 连续输入：编辑不会被打断

想连着加一串节点时，不用反复点鼠标：

1. 选中一个节点 → `Tab` 加子节点 → 直接打字
2. 编辑框里再按 `Tab` ＝ **保存当前这个 + 新建它的子节点**
3. 按 `Enter` ＝ 保存并结束编辑；想平着往后加，就回到画布按 `Enter` 加同级

几条硬保证：

- 进入编辑后，光标会一直留在编辑框里，直到你按 `Enter`（保存）、`Esc`（取消）或点别处。
- 后台任务（自动备份、本地存档、自动重排）只是**读取**你正在输入的内容，不会把编辑框收走，打了一半的字也不会被中途落库。
- 编辑中想换行用 `Shift+Enter`（单独 `Enter` 是保存）。

### 3.3 多选批量整理

| 操作 | 做法 |
| --- | --- |
| 加选 / 减选 | `Ctrl`（macOS 用 `⌘`）+ 点击节点，点第二下取消 |
| 追加 | `Shift` + 点击 |
| **框选** | 按住 `Shift`（或 `Ctrl`）在空白处拖出矩形，框住的全选中（**不按修饰键的拖拽仍是平移画布**） |
| 批量删除 | 选中后按 `Delete`（只处理最外层节点，子树跟着走；一次 `Ctrl+Z` 整批回来） |
| 批量折叠 / 展开 | 选中后按 `空格` |
| 批量上色 / 贴标记 | 右键菜单里的色块与标记按钮 |

主节点是实线选中框、其余成员是蓝圈；左下角会写「已选中 N 个节点（含下级共 M 个）」。

### 3.4 拖拽改挂

结构调整不必删了重加：**按住鼠标左键把 A 节点拖到 B 节点上松手**，A 和它的所有下级会整棵挂到 B 下面。

- 拖动时鼠标旁跟着一条提示「挂到『XX』下」，目标节点高亮描边。
- 拖到**中心主题**上 ＝ 升为一级分支；拖回**原来的父节点** ＝ 挪到同级末尾（可用来调顺序）。
- 三种情况会被拦住并提示：**根节点**不能拖；拖到**自己身上**无效；拖进**自己的下级**会造成死循环（提示条变红）。
- 移动超过 5 像素才算拖拽，所以单击选中、双击编辑都不受影响；拖错了 `Ctrl+Z` 撤回。

> 嫌画布上拖要缩放了才能看到目标？**左侧「☰ 大纲」里也能拖着排序 / 改挂**，还能用 `Alt+↑↓` 在当前层级挪一位 —— 长列表里挪一大段时比画布顺手得多（见 [4.4](#44-大纲视图)）。

### 3.5 展开、折叠与层级

- 节点右侧的**小圆圈**就是折叠开关：`−`＝已展开（点一下收起），`+`＝已折叠（高亮实心，点一下展开）。手动折叠状态会**存进文件**，切层级、刷新页面都还在。
- **展开全部**：一次打开所有层级（层级回到「全部」，手动折叠也一并放开）。
- **仅看主干**：等同层级选「1 层」，只留中心主题和第一层分支。
- **层级下拉**：只看前 1~6 层。被截掉的分支显示成**虚线圈**并带 `+N` 角标（N＝还有多少个下级没显示）；点某一支的 `＋` **只展开这一支**，其余仍按所选层级显示，再点一下收回。被截断的节点不会再往外拖连线，画面干净不凌乱。
- 「层级」和「仅看主干 / 展开全部」是**同一套状态**：主干＝1 层、展开全部＝全部，按钮和下拉永远同步。「层级」只影响查看，不动节点数据；手动折叠过的分支切层级也不会被冲掉。

### 3.6 节点备注

**右键 →「编辑备注」**（或 `Ctrl+Shift+M`）给节点写一段多行说明，比如验收标准、链接、待办背景。

- 有备注的节点**右上角挂一个小角标**，鼠标悬停看全文；左侧大纲对应行也会挂一个小铅笔。
- 角标是**绝对定位**的，不占节点内部空间 —— 加不加备注，节点宽高、列宽、连线位置完全不变。
- 浮层里 `Ctrl+Enter` 保存、`Esc` 取消，**留空保存＝删除备注**，`Ctrl+Z` 可撤回。
- 备注跟着导图一起存、一起导出（落点见 [7.3](#73-备注标记链接的落点)）。
- 想给某个分支补一段说明又不想污染节点文字时，这就是它该待的地方。

### 3.7 语义标记

备注是「一段长文字」，标记是「一眼可见的小图标」。右键菜单里有一整排**标记**按钮，内置固定 5 颗：

| 标记 | 含义 |
| --- | --- |
| ⭐ | 重点 |
| ❗ | 风险 |
| ❓ | 待确认 |
| ✅ | 完成 |
| 🔒 | 已定稿 |

- 标记画在节点**左上角**小角标里 —— 跟备注编号（右上角）、长文字截断角标（左下角）**三个角错开**，同时存在也不会叠字。
- **多选时整批生效**（只取最外层，避免同一子树被重复处理）；整批都是同一颗时**再点一次＝取消**。
- 角标绝对定位，不占节点内部空间，节点宽高与连线一个像素都不变。
- 左侧大纲里标记排在文字**前面**，扫一眼就能看到哪几行有风险。
- **📊 统计**面板里会出现「语义标记」小节，直接回答「本图有几个风险点」。
- 没贴标记的节点不写字段、不画角标，所以老文件读进来存回去形状完全不变。`Ctrl+Z` 可以撤回贴错的标记。

### 3.8 节点链接

资料整理、读书笔记、项目清单里，一个节点常要指向一份外部材料 —— 一个网页、一份本地 PDF、一个共享目录。以前只能把地址写进节点名字（又长又丑）或备注（看不见），现在有了专门字段：

| 想做什么 | 怎么做 |
| --- | --- |
| 挂上 | 选中节点 → 右键「编辑链接」或 `Ctrl+Shift+L` |
| 打开 | 点节点右上角的链环，或 **`Alt+单击`** 节点 |
| 改 / 清 | 同一个面板里改；**留空并保存＝清除** |
| 看见谁挂了 | 大纲行尾也有链环；「📊 统计」会数出「挂了链接 N 个节点」 |

**`Ctrl+单击` 仍然是「加选」** —— 打开链接刻意走 `Alt`，两个动作不互相抢。

**网页链接和本机路径，结果不一样**（这是浏览器的限制，不是本工具偷懒）：

| 你挂的是 | 点一下会发生什么 |
| --- | --- |
| `https://…` / `http://…` / 邮件 / 电话 | **新标签页打开** |
| `D:\资料\x.pdf` / `/Users/a/b.md` / 相对路径 | **复制到剪贴板**，并提示「粘到资源管理器 / Finder 地址栏」 |

浏览器**不允许**网页直接打开 `file://` 或本地路径 —— 硬跳只会静默失败。所以这里选择把路径复制下来，并把原因说清楚，而不是假装成功。

**危险地址一律不认**：`javascript:` / `data:` 这类能执行脚本的地址存不进去、打不开、也不会出现在任何导出里 —— 导出的独立 HTML 是要发给别人双击打开的，一个 `javascript:` 链接就是现成的 XSS。

### 3.9 长文字与节点宽度

节点文字最多显示 4 行。**被截断时节点左下角会出现一个 `⋯` 小角标**（以前是静默吃掉，你根本不知道有字没显示），鼠标悬停即可看全文，双击进编辑框也能看完整内容。

想让长文字显示得更完整：顶部「宽度」把节点调宽，或选**「自适应」**—— 短的节点自动收窄、长的放宽到 420px，画面更紧凑。

## 4 查找与整理

### 4.1 搜索

节点一多就别肉眼找了，点顶部 **🔍 搜索** 或按 `Ctrl+F`：

- 输入即搜，命中节点**橙色描边**，没命中的整体淡出，一眼锁定；
- 顶部搜索条显示「第几个 / 共几个」，`Enter` / `↓` 下一个、`Shift+Enter` / `↑` 上一个，循环跳转；
- 跳转会**自动展开折叠的父级**、自动放开层级限制，并把画面平移到命中节点；
- 勾选**「只看命中」**：没有命中内容的分支整体收起（带虚线圈和 `+N` 角标），画布上只剩命中路径；
- `Esc` 或点 × 关闭，高亮一并清掉。

**搜索也管备注**：备注文字同样会被搜到。只靠备注命中的节点用**青色虚线框**（标题命中是橙色实线框），计数条会另外标一句「· 备注 N」，一眼就知道这几个是「备注里有」而不是「标题里有」。

**三个匹配开关**（搜索框右边）：

| 开关 | 作用 | 什么时候用 |
| --- | --- | --- |
| **Aa** 区分大小写 | 关掉（默认）时 `apple` 能搜到 `Apple`；打开后严格区分 | 要精确找 `API` 而不是 `api` |
| **全词** | 前后不能再接字母 / 数字 / 下划线 | 找 `apple` 时不想要 `pineapple` |
| **.*** 正则 | 把输入当正则表达式，支持分组 | 清理脏数据，比如 `^[0-9]+\. *` 一键去行首编号 |

三个开关点一下就切换，并且**立刻用新口径重搜一遍**，不用再敲关键词。开了正则后「全词」自动置灰（正则里直接写 `\b` 即可），不会给你一个按了没反应的按钮。

**正则写错了怎么办？** 不会崩、不会弹报错框：输入框**描红**，右边给一句「正则写错了，已按普通文字搜索」，然后**退化成按普通文字搜**。改对了红字自动消失。

### 4.2 批量替换

搜到一大堆要统一改名的节点（导入时带下来的统一前缀、写错的术语），不用一个个点：搜索条上有**「替换为…」**输入框，填好点替换，就对**当前全部命中节点**做一次批量替换。

- **替换跟你正在用的搜索口径完全一致** —— 开了 `Aa` 就按大小写、开了「全词」就按全词、开了正则就能用 `$1` 引用分组；
- **只改标题，不动备注**。备注里命中的节点不会被替换（替换完会提示「命中的都在备注里」）；
- 整批只压**一个撤销点**，`Ctrl+Z` 一次全撤回；
- 替换完重新算一遍命中，能马上看到结果；不搜就不替换，不会误伤别处。

### 4.3 批量文本清洗（🧹 批量）

导入一堆脏数据后最痛的是「统一清洗」。搜索条上有 **「🧹 批量」** 按钮，打开一个面板，**作用范围二选一**（面板上实时显示各自有几个节点）：

- **搜索命中的节点** —— 先 `Ctrl+F` 搜一段文字，再进来处理这一批；
- **画布上选中的节点** —— `Ctrl` / `Shift` 多选好再进来。

面板里四组操作：

| 组 | 操作 | 说明 |
| --- | --- | --- |
| 前后缀 | 加前缀 / 加后缀 | 各带一个输入框和一颗按钮，给这一批节点统一加上同一段文字 |
| 清洗 | 去行首编号 / 去首尾空白 / 全角→半角 / 半角→全角 | 适合从 Word / 网页粘下来带编号、带全角标点的脏标题 |
| 拆分 | 按分隔符拆成子节点 | 填一个分隔符（如 `、`），把**当前选中的那一个**节点拆成多个子节点。**非破坏性**：原节点文字不动，拆出来的当子节点 |
| 合并 | 把选中的多个节点合并为一个 | 按画布先后顺序取第一个当结果，接管其余节点**及其子节点**；可自定义连接符（默认 ` / `） |

几条值得知道的：

- **整批只压一个撤销点**，`Ctrl+Z` 一次全撤回；
- **只改标题，绝不碰备注** —— 和「批量替换」「搜索」是同一套口径；
- 一个节点都不用改时**不写撤销栈**，只提示「这 N 个节点里没有可清洗的」，反复点不会刷满撤销栈；
- **「去行首编号」会认**：`- * + •`、`1. / 1.1 / (2) / 一、/ 第一章` 这些常见形状；**数字后面必须跟分隔符**，所以「2024 年会」不会被削成「年会」；
- 多级编号 `1.1` 和小数 `3.14` 形状上分不开，本功能按编号处理 —— 削错了 `Ctrl+Z` 就能回来；
- 面板里按 `Esc` 关掉，`Enter` 直接触发输入框对应的那个动作。

### 4.4 大纲视图

顶部 **「☰ 大纲」** 打开左侧栏，把整棵树按缩进列出来（带折叠三角和条目计数）。

- **单击一行** → 画布跳到那个节点（沿途折叠自动展开；如果有「只看命中」或层级限制挡着，会自动放开，保证跳过去真能看到它）。
- **双击行里的文字** → 就地改名。
- **拖着一行走** → 在侧栏里直接调顺序 / 改挂，不用回画布缩放定位：
  - 拖到某行的**上缘 / 下缘**（各行上下各 28% 的区域）＝排到它前面 / 后面，落点处出现一道强调色细线；
  - 拖到某行的**中间**＝变成它的子节点，整行描边 + 半透明底色；
  - 拖到**自己的下级**上会被拦住，整行**标红**并说明原因；
  - 放进折叠着的节点会自动展开，松手就能看到结果；拖动中源行会变淡。
- **`Alt+↑` / `Alt+↓`** → 在当前层级里上下挪一位（和画布上的 `Alt+↑↓` 是同一个动作）。
- 折叠三角只管结构、不会把视图跳走；`Esc`、右上角 ×、再点一次工具栏按钮都能收起；侧栏展开时画布自动右移让位。
- 拖错了 / 挪错了，`Ctrl+Z` 都能撤回。

### 4.5 结构统计

顶部 **「📊 统计」** 打开面板：节点总数、最大深度、叶子数、折叠数、**各层级节点数分布**、**各一级分支占比**（配色和画布上的分支配色一致），以及**语义标记汇总**（有标记时才出现，形如「⭐ 重点 2　❗ 风险 3」）。

还有一小节 **「渲染」**：上次渲染花了多少毫秒、累计渲染多少次、当前显示多少个节点。图大到一定程度（400 节点以上）且上次渲染超过 60ms 时，下面会补一句**可操作的建议** —— 直接说「折叠不看的整支，或用『显示到第 N 层』把深度卡住」，而不是只告诉你「慢」。

统计的是**整张导图**，和折叠 / 层级限制无关；面板开着时改画布会**实时刷新**。

| --- | --- |
| 平移 | 在空白处按住鼠标拖动 |
| 缩放 | `Ctrl` / `⌘` + 滚轮（以光标位置为中心），或右上角 ＋ / − |

### 5.2 布局：左右 / 上下

顶部「层级」旁边有一个 **布局** 下拉，只有两项：

| 选项 | 长什么样 | 什么时候用 |
| --- | --- | --- |
| **左右**（默认） | 中心主题在左，分支一层层往右展开 | 发散思考、读书笔记、需求拆解 —— 想「往外长」的时候 |
| **上下** | 中心主题在最上面，一层层往下铺，同一层的兄弟并排 | 汇报关系、组织架构、任务分解（WBS）、家谱 —— 要「从上往下读」的时候 |

几个说明：

- **切换不改数据**：同一份导图换个方向看而已，文字、备注、标记、顺序全都原样；`Ctrl+Z` 里也不会多出一条「切布局」。
- **方向键跟着翻**：左右布局是 `←` 回父级、`→` 进子级、`↑↓` 在同层挪；上下布局换成 `↑` 回父级、`↓` 进子级、`←→` 在同层挪。图转了手还按老习惯，方向感会完全错乱。

- **会记住**：和主题、配色一样存进偏好，关掉页面再打开还是上次那个方向；导出成独立 HTML 时也会带过去。
- 切换后会自动「适应窗口」一次。

### 5.3 沉浸全屏

点顶部 **⛶ 全屏**，或按 `F` / `F11`。进入后**顶部那排功能栏一并隐藏**，画布铺满整个屏幕，只剩导图本身 —— 适合投屏汇报、截图或安安静静想事情。

想用工具栏时不用退出全屏：

- **把鼠标移到屏幕最顶端**（距顶边 8px 内）→ 工具栏滑下来，鼠标移开自动收回；
- 右上角常驻一个半透明的 **⛶ 退出全屏** 悬浮按钮（鼠标移过去变清晰）；
- 按 `Esc` / `F` / `F11` 退出，回到带工具栏的普通视图。

如果运行环境不允许浏览器全屏（比如被嵌在某些预览窗口里），会自动降级为**沉浸模式**：不调系统的全屏 API，但照样把工具栏藏起来、画布顶格，同样用上面的方式退出。

### 5.4 缩略图导航

节点够多（8 个以上）时，画布右下角会出现一张**整图缩略图**，上面有个框表示当前视口：

- **点一下** → 视口跳到那里；
- **按住拖动** → 连续导航，像拖地图一样；
- 节点少的时候它不出现，不占地方。

### 5.5 左下角使用指南

左下角那块提示（快捷键一览 + 当前选中信息）可以收起，让画面更干净：

- 点提示框右上角的 **收起 ×**，或点顶部 **隐藏指南** → 收起成一个 `?` 小圆点。
- 收起后**把鼠标移到左下角那个 `?` 上**，指南自动展开；移开就收回。
- 想固定显示，点一下那个 `?`，或再点顶部按钮。
- 收起状态会被记住，导出成独立 HTML 时也会带着。

## 6 外观

顶部最右侧一组，改动会**自动记住**，下次打开还是这个样子。

### 6.1 字体、字号、字重、宽度

**字体（6 种方案，Windows 上每一档都真实不同）**

| 方案 | 特点 |
| --- | --- |
| **Segoe＋雅黑**（默认，推荐） | 英文用 Segoe UI（小字号最利落），中文自动落到微软雅黑（专为屏幕 / ClearType 优化）。导出的 PNG、Word、PPT 用同一套 |
| 微软雅黑 | 中英统一，观感最饱满 |
| 等线 DengXian | 比雅黑清瘦、字面更紧，节点多时更透气 |
| 黑体 SimHei | 最粗重醒目，适合投影 / 分享截图 |
| 宋体（衬线） | 偏正式 / 打印 |
| 系统默认 | 不指定中文字体，交给浏览器 |

> 早期版本的「Microsoft YaHei UI」选项在 Chrome 下与「Microsoft YaHei」渲染像素完全相同，已移除；现在每一档切换都能看到明显差别。

**字号（4 档）**：小 / 标准 / 大 / 特大。除根节点外所有节点用同一个字号（过去 13px 与 13.5px 混用，0.5px 的差别看不出层级、只觉得参差）；根节点比其余大一档，层级一眼可辨。

**字重（3 种）**：层级区分（默认：根节点和分支加粗、末级常规）/ 全部常规 / 全部加粗。

**宽度（5 档）**：窄 / 标准（默认）/ 宽 / 超宽 / 自适应。自适应档短的节点自动收窄、长的按内容放宽（上限 420px），布局列宽跟着实测宽度走，导出 PNG / PPT 也是同样宽度。

### 6.2 主题、配色、背景

- **主题（9 套）**：日间、极简白、清新薄荷、米黄护眼、商务深蓝、水墨素雅、高级灰、夜间、午夜蓝
- **配色（8 套）**：多彩活力、糖果马卡龙、清新自然、海洋蓝调、商务藏青、莫兰迪、大地暖色、素雅灰
- **背景（4 种）**：纯色、点阵、网格、横线

**根节点和顶栏的颜色是跟着主题走的**：日间主题下根节点是亮蓝 `#2f6fed`、顶栏白色；「商务深蓝」等主题本身就是深色顶栏 + 深色根节点。如果发现它们「变黑了」，多半是主题被切换了（下拉选完仍带焦点时，接着滚滚轮就会误改）—— 现在选完下拉会自动放开焦点，不再误触；万一已经改了，点「默认外观」一键复原。

### 6.3 默认外观与搭配建议

**默认外观（一键复原）**：主题 / 配色 / 底纹被改乱时，点「默认外观」立刻回到出厂的蓝色样子（日间 + 多彩活力 + 点阵），只动外观、不碰画布内容。

| 想要的感觉 | 推荐组合 |
| --- | --- |
| 年轻、清新 | 清新薄荷 / 极简白 + 清新自然 或 糖果马卡龙 + 点阵 |
| 商务、沉稳 | 商务深蓝 / 高级灰 + 商务藏青 或 莫兰迪 + 纯色 |
| 长时间看 / 护眼 | 米黄护眼 + 大地暖色 |
| 夜间写东西 | 午夜蓝 / 夜间（节点边框会自动提亮，深层节点也看得清） |

### 6.4 关于字重：为什么有的字粗、有的不粗

画布上的字重默认**按层级区分**：根节点和有下级的分支用**粗体**，末级叶子用**常规** —— 这是刻意的视觉层级，帮你一眼分清主干和细节。不喜欢的话，顶部「粗细」选**全部常规 / 全部加粗**即可整幅统一。

早期版本还有一层「假加粗」在捣乱：CSS 里写了 `font-weight:650/600` 这类中间档，而微软雅黑只有**常规（400）和粗体（700）两个真字重**，中间档会被浏览器合成「伪粗体」—— 描边发糊、不同元素粗细还不一致。现在全站只保留 400 / 700 两档真字重。

### 6.5 界面语言：中文 / English

顶部最右侧那个 `EN` / `中文` 按钮，一键切换整个界面语言。**按钮上写的是「点一下会变成什么」** —— 显示 `EN` 时说明现在中文、点完变英文；显示 `中文` 时反过来。这是 Gmail、GitHub 的老约定，比显示「当前语言」少一次猜测。

| 会跟着变 | 不会变 |
| --- | --- |
| 顶栏按钮、下拉选项、右键菜单 | 画布上节点的文字 |
| 14 个面板的标题、说明、按钮 | 节点备注、节点链接 |
| 全部提示条（含撤销步骤名） | 你自己起的导图名 / 文件名 |
| 快捷键速查表的每一条说明 | 粘贴 / 导入进来的原文 |
| 导出内容里的表头与说明文字 | — |

几条你可能在意的：

- **切回中文是逐字还原**，不是「再翻一次」。原文在第一次翻译时就留在页面上，回切时直接放回去 —— 所以「标准」这种既是字号又是宽度的词，不会因为一次往返就串到别的面板去。
- **语言是偏好，不是数据**：记在本机（和主题、配色同一份设置），不进导图数据、不压撤销栈。换语言不会让 `Ctrl+Z` 凭空多出一步。
- **全新用户**还没动过手时，中心主题也跟着换（`中心主题` ↔ `Central topic`）；一旦改过任何东西（撤销栈里有记录），节点文字就当用户内容，一个字都不动。
- **英文下界面会宽一点**：右键菜单中文 311px、英文 348px（+12%），顶栏不横向溢出、按钮里的字也不会被裁 —— 这两条都有真 Chrome 的量测守着。
- **手册配图用你说的那种语言**：本文与 [README.zh-CN.md](../README.zh-CN.md) 的图都是**中文界面**（`screenshots/*.png`）；英文版手册与 README 用的是英文界面那一套（`*.en.png`）。工具本身没差别，只是各语言文档指向各自那套图。

## 7 导出

### 7.1 面板与快捷键

点顶部 **「导出 ▾」**。面板里的格式**按用途分成三组**（图片类 / Office 办公 / 数据与互通），每组内两个一列排开，找起来比一整列快。**前 9 个格式带数字快捷键**：面板开着时直接按 `1`~`9` 就导；`Esc` 关闭面板。上次用过的格式，下次打开面板会标一个「上次用到」角标。

  <img src="../screenshots/mindmap-export.png" width="760" alt="导出面板：图片类 / Office 办公 / 数据与互通三组，共 12 种格式"/>
</p>

- **只导出某个分支？** 勾上 **「仅导出选中分支」**，12 种格式就都只输出当前选中节点及其子树（注意：勾选后不会自动取消，导完记得取消）。

### 7.2 12 种格式对照

| 格式 | 用途 | 导出范围 | 备注怎么带 |
| --- | --- | --- | --- |
| **PPT · 整图一页** `.pptx` | 把导图画成**矢量图形放进一张幻灯片**，可在 PowerPoint 里继续拖动改色 | 屏幕上看到的样子 | 节点形状内多一行更小的灰字（文字太小被省略时不带，免得溢出形状） |

| **OPML 大纲** `.opml` | 大纲交换的通用格式：XMind / 幕布 / Workflowy / 飞书都能直接打开，也能反过来导入本工具 | 全部节点 | 写在 `_note` 属性上（换行正确编码，多行备注不丢） |
| **Markdown** `.md` | 标准 `#` 标题大纲，可贴回笔记 / 语雀 / Notion | 全部节点 | `> 备注：…` 引用块（**再导入本工具能读回节点上**） |
| **图片** `.png` | 2 倍高清位图，适合贴进文档、PPT、聊天窗口 | 屏幕上看到的样子 | 节点右上角挂**编号**角标，图下方附「备注」清单 |
| **SVG 矢量图** `.svg` | 放大不模糊，可直接插进 Word / PPT / 网页，也能用 Illustrator 继续编辑 | 屏幕上看到的样子 | 同 PNG：编号角标 + 图下方清单 |
| **PDF** `.pdf` | 调起打印 → 选「另存为 PDF」，矢量清晰 | 屏幕上看到的样子 | 文末自动附一份「备注」清单 |
| **独立网页** `.html` | 双击就能打开，内容完整且**还能继续编辑**，分享给别人最方便 | 全部节点 | 自动带（数据里就有） |
| **导图数据** `.json` | 本工具专用格式，用「打开」可继续编辑，是主要备份方式 | 全部节点 | 自动带（数据里就有） |

> 一句话记忆：**图片 / SVG / PDF / PPT·整图一页** 导出「当前屏幕上看到的样子」（含折叠和层级限制）；其余格式一律导出**全部节点**。

### 7.3 备注、标记、链接的落点

| 格式 | 备注 | 语义标记 | 节点链接 |
| --- | --- | --- | --- |
| JSON / 独立网页 | 自动带 | 自动带 | 自动带 |
| Markdown / 复制为 Markdown | `> 备注：…` 引用块，可再导入 | 图标写在节点文字前 | 真链接 `[文字](https://…)`；本机路径写成 `> 链接：…` 附注 |
| Word | 缩进一级灰色小字 | 图标写在标题前 | 真链接（`w:hyperlink` + 外部关系，点了就跳） |
| Excel | 独立「备注」列 | 图标写在节点名里 | 多一列「链接」 |
| PPT · 分页大纲 | 节点后小字灰行 | 文字前加图标 | 节点下方一行蓝色小字 |
| PPT · 整图一页 | 形状内小字 | 文字前加图标 + 空格 | 文字前加 🔗 |
| XMind / OPML | `notes` / `_note` | 图标写在节点名里 | `href` / `_link` 字段 |
| PNG / SVG | 编号角标 + 图下方清单 | 节点左上角白底圆角方块 + 图标 | 右上角画同一枚链环角标 |
| 打印 / PDF | 文末附备注清单 | 文字前加图标 | 纸上是「链接」清单，把地址印出来 |

### 7.4 PPT「整图一页」的取舍

一张 16:9 幻灯片能装下的节点是有限的。节点太多时，等比缩小后字号会掉到 PowerPoint 的下限（1pt）以下，导出来只会是一片看不清的黑点。所以工具会：

1. 先尝试找一个**字号 ≥ 2pt**（正常视图下看得清）的最深层级；
2. 找不到就退一步，找**字号 ≥ 1pt** 的层级；
3. 还是不行，就输出**不带文字的纯结构色块图**。

需要裁剪时会弹框告诉你两个方案各自的**节点数和实际字号**，由你决定：点「确定」＝只画到某一层（字看得清、层级变浅）；点「取消」＝画全部节点但不带文字（保留完整结构）。

想要「全部节点 + 看得清」，请用 **PPT · 分页大纲**。另外，节点较多时先「仅看主干」或把层级调到 2~3 层再导出，效果最好。

## 8 保存与恢复

### 8.1 三层保险

建议至少用上前两层：

| 层级 | 存在哪儿 | 长什么样 | 能防什么 |
| --- | --- | --- | --- |
| ① 浏览器本地存档 | 浏览器 localStorage（`mindmap-studio-v1`） | 一个数据库条目，不是文件 | 误关页面、崩溃、重启 |
| ① 的附加：**历史快照** | 同上（`…:hist:xxx`） | 最多 10 份整棵树的 JSON | 误删 / 改乱之后回到早先的样子（关页面也还在） |
| ② **自动备份目录** | 你指定的 `auto_backup` 文件夹 | 真实的 `.html` 文件 | 换浏览器、清缓存、误删 |
| ③ 手动导出 | 你自己选的位置 | `.json` / `.html` / 其他格式 | 分享、归档、换电脑 |

### 8.2 本地存档与多页面隔离

- 每一步编辑都会自动存进 localStorage，关掉页面、重启浏览器都还在。
- 外观偏好单独存一份（`mindmap-studio-v1:prefs`）。
- 浏览器标签页标题会跟着根节点变（如 `mind_map · AI 学习笔记`），同时开好几张图时靠它分辨。
- ⚠️ 换浏览器、清理浏览器数据、无痕模式都会看不到之前的内容（历史快照同样如此，它也在浏览器里）。

同一浏览器里同时开好几个页面时，画布内容是**完全独立**的：

| 场景 | 行为 |
| --- | --- |
| 甲在做「项目A」，再开一个页面做「项目B」 | 新页面**空白起步**，不会显示甲的图 |
| 甲的改动 vs 乙的改动 | 各自写各自的槽，不会互相覆盖 |
| 各自按 F5 刷新 | 各自恢复自己那份 |
| 甲、乙都还开着时再开第三个页面 | **空白起步**（不会去偷别人正在用的存档） |
| 关掉甲、乙之后再开新页面 | 继承**最后关闭**的那一份（方便接着上次继续） |

实现上：标签页 id 存在 `sessionStorage`（浏览器按标签页隔离），槽内容存在 `localStorage`（同源共享），靠一张槽登记表 + 10 秒心跳判断「这个槽还有没有人用」；页面关闭时把槽标记为已释放，下次可被继承。槽最多保留 24 个、7 天后清理。

**自动备份也做了防撞**：两个页面备份同名导图时，后写的那个会自动另存一份带时间戳的（如 `AI 学习笔记-20260929-073100.html`），不会覆盖对方的文件；对方页面关闭后才会接管原文件名。

### 8.3 历史快照（🕘 历史）

改动画布时，工具会在浏览器里**自动留一份整棵树的快照**。它补的是 `Ctrl+Z` 补不了的那一块 —— 撤销栈在内存里，**一关页面就没了**；快照存在 localStorage 里，第二天发现后悔也回得去。

| 细节 | 说明 |
| --- | --- |
| 什么时候记 | 改动后自动记，**两份之间至少隔 3 分钟**；内容跟最新那份一样就不记 |
| 留几份 | **最多 10 份**，满了挤掉最老的（最新的排最上面） |
| 怎么打开 | 顶部工具栏 **🕘 历史** |
| 能做什么 | **回到这里**（回滚）/ **另存**（单独存成 `.json`，文件名带时间戳）/ **删**（只删这一份） |
| 回滚安全吗 | 回滚**前会先压一条撤销栈**，所以「回到历史」本身也能撤回；还会先弹确认框，框里就能顺手备份一份 `.json` |
| 替换整张图时 | 新建空白 / 打开 / 导入 / 套模板 / 清空画布之前，**会自动先留一份旧图** |
| 空间不够时 | 快照写不进去就**静默放弃**，主存档照常 —— 它是附庸，不能反过来拖垮正事 |
| 清空 | 面板底部「清空历史」，要**连点两次**才生效；只清快照，画布内容不动 |

⚠️ 快照也在浏览器里：换浏览器、清缓存一样会没。**要长期留底请用「导出 ▾ → 导图数据 .json」**。

### 8.4 撤销历史（↩ 步骤）

`Ctrl+Z` 只知道「退一步」，但大图整理时你真正想知道的是**退到哪、退掉的是哪一步**。顶部 **↩ 步骤** 把当前这段历史摊开成一条时间轴：

| 区域 | 内容 |
| --- | --- |
| 上面一段（虚线） | **可重做**：刚才撤掉的那些，点一行就往前走 |
| 中间一行（高亮） | **现在的内容**，不可点 |
| 下面一段 | **可撤销**：从「刚发生的那一步」往下排到最早的一步 |

每行都写清它是什么操作（「上色 3 个节点」「粘贴「需求清单」」「导入「周报.md」」），后面跟着「撤销 N 步回到这里」和时间。**点任意一行 = 连按那么多次 `Ctrl+Z`** —— 两者结果完全一致（栈的内容、顺序、丢弃计数都一样），只是不用一下一下按。

- 打开面板后**能撤到的最早那一步在最后一行**，点它就是「回到最初的图」。
- 面板开头写清「现在能撤销 N 步、重做 M 步」；如果因为内存封顶丢掉过更早的步骤，会**如实说明丢了几步**。
- 记录只在内存里：**关掉页面就没了**。要长期留底请用「🕘 历史」或导出文件。
- 键盘：打开后焦点就在第一行，`↑↓` 看，`Enter` / 空格 = 点那一行，`Esc` 关掉并回到原来那颗按钮。
- 撤销 / 重做的提示也会说出名字（「已撤销：删除「市场部」」），不用猜刚才撤了什么。

### 8.5 工作区（🗂 工作区）

每个标签页各占一个存档槽（最多 24 个），点顶部 **🗂 工作区** 能看到全部页签：

| 能做什么 | 怎么做 |
| --- | --- |
| **看见** | 每行显示名字（没起名字就用根节点文字）、节点数、「多久以前动过」；当前这页标 **本页签**、还开在别的标签页里的标 **其它页面开着** |
| **切过去** | 点「打开」：当前这页先存好，再整页换成那一页（撤销栈清空，换了一整张图，撤回去没有意义） |
| **单独另存** | 点「另存」：只把这一页存成 `.json`，文件名就是清单里那个名字 |
| **删掉** | 点「删」→ 按钮变成「确定删」→ 再点一次才真删；它的历史快照一并清掉 |
| **整包搬走** | 「导出工作区包…」把全部页签装进一个 `.json`（`工作区-8个页签-20261018-1735.json`） |
| **整包搬回来** | 在另一台机器上点「导入工作区包…」，或直接把它拖进画布 |

导入有三条**不会伤到已有内容**的规矩：

- **只新增，不覆盖**：导进来的每个页签都是新槽，同一个包导两次就是两份（想清理再删）。
- **绝不挤掉老页签**：工作区满 24 个时**直接拒绝并告诉你**，不会偷偷删「最久没动」的那个。先删几个再来。
- **旧时间戳不带进来**：包是十天前打的，导进来也按「刚刚」算 —— 否则会被 7 天过期的清理规则当场清掉。

> 导入的页签是**「已关闭」状态**，所以能立刻打开；反过来，如果某一行标着「其它页面开着」，「打开」和「删」都是禁用的 —— 两个页面同时写一份存档必然互相覆盖，这是唯一不能让步的一条。

### 8.6 自动备份到 auto_backup 目录

开启后，每次改动会**静默把整张导图写成一个独立的 HTML 文件**，存进 `auto_backup` 目录，**文件名就是根节点的内容**（如 `AI 学习笔记.html`）。备份件双击即可打开、还能继续编辑，等于一份「能用的副本」。

**怎么开**：点顶部 **「自动备份 · 未开启」** → **选择目录** → 选中 `mind_map.html` 所在的文件夹 → 工具会自动在里面建 `auto_backup` 子目录。

| 细节 | 说明 |
| --- | --- |
| 触发时机 | 每次改动后 3 秒（节流），不会边打字边写盘 |
| 正在编辑时 | **不会打断打字**。备份读取编辑框里「此刻正在输入」的内容，但光标和编辑框全程不动 |
| 文件名 | 取根节点内容，自动去掉 `\/:*?"<>\|` 等非法字符，最长 60 字 |
| 覆盖保护 | 节点数骤降一半以上（误清空、删掉整个大分支）时**不覆盖旧文件**，改存带时间戳的 `名称-20260928-081500.html` |
| 权限 | 用的是 File System Access API，第一次需点一次「选择目录」授权；句柄存在 IndexedDB，之后自动续用 |
| 暂停与恢复 | 浏览器收回权限时状态变「已暂停」，面板里点 **恢复** 重新授权 |
| 浏览器要求 | Edge / Chrome 等 Chromium 系。Firefox、Safari 不支持 —— 按钮显示「浏览器不支持」，请改用「导出 ▾ → 独立网页」 |

⚠️ 安全策略限制：**本地 `file://` 网页无法自己创建目录**，所以第一次必须由你手动选一次目录（这是浏览器故意设计的，防止网页偷偷写你的磁盘）。之后就全自动了。

### 8.7 替换与清空前的提醒

- **替换画布前的提醒**：点「新建空白」「打开」，或把 `.json` / `.xmind` / `.opml` 直接拖进画布时，如果画布上已有内容，会弹确认框并直接给三个按钮 —— **备份 .json 并继续**、**备份网页并继续**、**不备份，直接继续**。
- **清空画布**（右上角红色按钮）：会二次确认，告诉你将清掉多少节点，清空后 `Ctrl+Z` 还能整棵找回来。

💡 一句话：**开了自动备份，就不用担心误删和清缓存**；重要的图再顺手导出一份 `.json`，就是完整的三重保险。

### 8.8 存储写不进去时

本地存档写失败分两种，提示也是两句不同的话：

- **空间满了** → 提示「本地存储已满」。工具会先**自救一次**：把别的标签页已经关掉一小时以上的旧存档（连它的历史快照一起）清掉，然后重试；腾出空间就报「已腾出本地存储 · 清掉了 N 份」。**永远不会动你自己的槽，也永远不会动别的页面还开着的槽。**
- **浏览器压根不让写**（无痕模式等）→ 提示「本地存储不可用」，这种情况只能改用导出。

📊 统计面板里有一节「本机存档与撤销」，能看到：可撤销几步 / 约占多少内存、可重做几步、历史快照几份、本机存档占用多少，以及**撤销栈封顶之后「更早的 N 步已放不下」**这种降级状态。

> 撤销栈有**两条上界**：最多 80 步，**且**总内存不超过 6 MB。大图一步快照就有 100 KB 上下，所以步数会被内存这条线先卡住 —— 这是有意为之，免得一张大图把浏览器内存吃干。

## 9 键盘与触屏

### 9.1 快捷键速查

记不住键位不用翻文档：点顶部 **⌨ 快捷键**，或在画布上按 **`?`** / **`F1`**，弹出按功能分组的速查表。

- **六组分类**：节点编辑 / 节点导航 / 复制·撤销 / 搜索·备注 / 视图 / 面板，共 29 条，每条都写了「这个键做什么」。
- **只在画布上生效**：前提是焦点不在输入框里（在搜索框、备注框里按 `?` 就是打一个问号）；其它面板打开时也不会抢键。
- **浏览器快捷键冲突审查**，结论直接标在表里：
  - 带 **⚠** 的键浏览器可能自己也要用，所以**额外配了备用键** —— `Ctrl+Shift+C`（复制为纯文本）在部分浏览器里是开发者工具「审查元素」→ 备用 `Ctrl+Alt+C`；`F1` 是浏览器帮助页 → 备用 `?`。主键照旧能用，真被抢走了就用备用键。
  - `Ctrl+D`（克隆节点）虽然和浏览器「添加书签」同键，但本工具能把它拦下来，所以不算冲突，只在说明里注明。
  - `Ctrl+Z` / `Ctrl+Y` / `空格` / 方向键这些浏览器默认行为，本工具均已拦下（写在对应条目说明里）。
- `Esc` 在任何面板打开时都能关掉它，**并且焦点会回到你刚才按的那个按钮**。

### 9.2 纯键盘走全流程

- **画布**：`Tab` / `Enter` / `F2` / `Delete` / 空格折叠 / 方向键导航 / `Alt+↑↓` 挪位，全都有。
- **大纲栏**：整棵树只占**一个** `Tab` 站点；进去之后 `↑↓` 走行、`←/→` 折叠展开、`Enter` 定位、`F2` 改名（屏幕阅读器会读出行层级与「已展开 / 已折叠」）。
- **缩略图**：`Tab` 到右下角那张小图后，`Home` / `End` 跳到第一个 / 最后一个一级分支，`←/→` 在分支之间走 —— 等价于用鼠标点缩略图上的那个位置。
- **面板**：打开后焦点直接进到面板内部，`Tab` 只在面板里循环、**不会跑到背后被遮住的工具栏上**；`Esc` 关闭并把焦点还给刚才那个按钮。
- 纯键盘操作时有一圈**高亮焦点框**（画布里的节点高亮用的是另一套配色，两者不会打架）。

### 9.3 触屏 / 平板

| 想做的事 | 手指怎么操作 |
| --- | --- |
| 平移画布 | 单指按住空白处拖 |
| 缩放 | **双指捏合 / 张开**（以两指中点为中心；两指同向推就是平移） |
| 选中节点 | 手指按一下节点（按下就选中，不用等抬手） |
| 改结构 | 按住节点拖到目标节点上松手（阈值比鼠标宽，手指抖一下不会被当成拖拽） |
| 打开右键菜单 | **长按节点约 0.5 秒**（会轻微震动一下） |
| 改文字 | 对节点**连点两下** |
| 折叠 / 展开 | 点节点右侧那个圆点（触屏下圆点放大到 26px，好按） |
| 挪视口 | 直接按住右下角缩略图拖 |

几个实现上的取舍，知道一下会更顺手：

- **第一次用手指碰画布会有一条提示**，说明上面这几个手势（只提示一次）。
- 手指按住后**移动超过 10px 才算拖拽**；鼠标是 3~5px。这是为了让「点一下」不被抖动误判。
- 触屏下长按不会选中节点里的文字、也不会弹系统菜单 —— 那个手势留给了「打开菜单」。编辑框里照常可以选择文字。

### 9.4 手机与窄屏（≤760px）

窄屏不是把桌面版硬塞进小屏幕，而是换一套外壳：

- 顶栏只留 **☰ + 标题**，其余功能收进**左侧滑入抽屉**。抽屉内容可以一直滚到最底下的「清空画布」；点 ☰、点遮罩、按 `Esc` 都能收起，点抽屉里的按钮会自动收起。
- 右下角圆形 **FAB「＋」** 点一下展开**常用操作面板**：子节点 / 同级 / 编辑 / 删子节点 / 删节点，点一项就执行并收起（点遮罩或按 `Esc` 收起）。没选中、选中中心主题、节点没有子节点时，对应项会自动置灰 —— 手机没有物理键盘，这几个键位得用手点。
- 抽屉和面板都是**浮层**，不撑高顶栏，画布始终铺满。
- **长按只出本工具的菜单**：节点、角标、画布背景在手机上都不能被选中，安卓 / iOS 自带的「复制 / 搜索 / 全选 / 翻译」条不会再冒出来抢位置；编辑框里照常能选中文字、放光标。右键菜单条目多时会自己限高滚动，最底下的「删除所有子节点 / 删除该节点」一定滚得到。
- **空白画布不放提示**：手机上只显示中心主题一个节点，不再叠一层「画布还是空的 / 按 Tab 加子节点」（手机没有 Tab 键，压在同一位置还挡字）。

## 10 常见问题

### 10.1 导入

**Q：Word / PDF 文件能直接导入吗？**
不能直接读文件。打开文档全选复制，粘贴进导入面板的文本框即可，识别效果和 `.md` / `.txt` 一样。

**Q：导入后一级分支特别多（几十上百个），太散了怎么办？**
说明原文是按 `1.` `2.` 这种编号写的。把「最多保留」调到 2~3 层重新生成，再用「层级」下拉分层查看，会清爽很多。

### 10.2 导出

**Q：导出的图片很大 / 很糊？**
PNG 默认 2 倍高清；导图超过浏览器画布上限（16384 像素）时会自动按比例降采样，此时字会变小 —— 建议先折叠到 2~3 层再导出。

**Q：导出时不想每次都选保存位置？**
取消导出面板底部「用『另存为』对话框保存」的勾选即可改回一键下载；这个选择会被记住。注意：下载下来的文件可能被下面那条安全策略拦住。

**Q：导出的 PPT 在别人电脑上显示不一样？**
PPT 用的是矢量图形，不依赖字体渲染差异；如果对方没装中文字体，字形可能有细微差别，属正常现象。

**Q：Windows 提示「无法打开这些文件，你的 Internet 安全设置阻止打开一个或多个文件」？**

这是 Windows 附件管理器干的：文件经**浏览器下载**下来时，会被打上一个「来自互联网」的隐藏标记（`Zone.Identifier`），图片查看器 / Word / PowerPoint 就可能拒绝打开。跟文件本身没关系，图是好的。三种处理方式任选其一：

1. **用「另存为」重新导出一次**（推荐，导出面板底部那个勾选默认就是开的）。工具走系统的另存为对话框把文件**直接写到磁盘**，绕开下载通道，写出的文件不带那个标记。
2. **给已经下载好的文件解锁**：右键文件 → 属性 → 底部「安全：此文件来自其他计算机」→ 勾 **解除锁定** → 确定。一堆文件想一次搞定，可以在 PowerShell 里跑 `Get-ChildItem "C:\Users\你的名字\Downloads\*.png" | Unblock-File`。
3. **把下载目录换个位置**：只有 Downloads 这类「下载区」才会被打标记，另存到桌面 / 文档目录通常没事。

> 「另存为」依赖浏览器的 File System Access API，Edge / Chrome 都支持（`file://` 双击打开本地工具也能用）。万一被系统策略禁用，工具会**自动退回下载**，不会卡住导不出来。

### 10.3 保存与数据

**Q：同时开好几个工具页面，内容会互相串吗？**
不会。每个标签页有独立的存档槽（详见 [8.2](#82-本地存档与多页面隔离)）。新开的页面一律**空白起步**，各自刷新各自恢复。只有当你**关掉**某个页面后再开新页面，才会继承最后关闭的那一份。

**Q：关掉一个页面后，它的图还能找回来吗？**
能。关掉页面只是把槽标记为「已释放」，内容还在；下次打开工具（或刷新别的标签页）会继承它。但如果槽被别的页面继承走了，或者超过 7 天没动过，就会被清理 —— 重要的图请开启自动备份或导出 `.json`。

**Q：升级到新版后，之前存的图还在吗？**
在。老版本把内容存在固定的 `mindmap-studio-v1` 一把钥匙下，新版第一次打开会自动把那份老存档**搬进**当前标签页的槽里，之后各存各的。

**Q：为什么第一次非得手动选目录，不能直接写死在工具旁边？**
这是浏览器的安全设计：本地网页不允许未授权地读写磁盘任意位置。所以第一次需要点一次「选择目录」授权，之后句柄存在 IndexedDB 里，只要不清浏览器数据就一直自动续用。

**Q：备份目录里出现带时间戳的文件（如 `XXX-20260928-081500.html`），正常吗？**
正常，那是保护机制被触发了。节点数骤降一半以上时，工具不会覆盖上一份好备份，而是另存一份带时间戳的版本。确认新的是你想要的之后，可以手动删掉旧的。

**Q：「自动备份」按钮显示「浏览器不支持」？**
该功能依赖 File System Access API，只有 Edge / Chrome 等 Chromium 系支持。Firefox、Safari 请用「导出 ▾ → 独立网页」手动备份，效果一样。

### 10.4 使用

**Q：能多人协作吗？**
不能，这是纯本地单机工具。协作方式是导出 `.html` 或 `.json` 发给对方，对方用「打开」继续编辑。

**Q：支持多大的图？**
实测 600+ 节点仍可流畅编辑。节点上千建议先折叠到 2~3 层再操作或导出。

**Q：手机上能用吗？**
能，见 [9.4](#94-手机与窄屏760px)。窄屏会自动切成 ☰ 抽屉 + FAB 的移动外壳，画布接管全部触屏手势。

## 11 技术实现

**体积与依赖**：单个 HTML 文件、**10258 行 / 595668 字节（约 582 KB）**，**零外部依赖**（没有任何 CDN、框架、字体外链），断网可用。

**布局**：自实现 tidy-tree（左→右）与纵向组织图（上→下）。两套共用同一份坐标语义（`x` = 节点左沿、`y` = 垂直中心），所以定位 / 边界 / 适应窗口 / 缩略图 / 框选一份代码通吃。每次渲染完整重算布局与贝塞尔连线，展开 / 折叠后不会错位；折叠的子树不进布局计算。

**渲染**：渲染主干**保持同步** —— `render()` 全文件 60 多处调用，导出 / `fitWidth` / 缩略图 / 大纲都要在它跑完之后**立刻**读 `flat` 和节点元素，异步化会把这些全部打乱。真正会一秒触发几十次的只有「搜索框边打边搜」这类输入，它们走 `renderSoon()`，用 `requestAnimationFrame` 把**同一帧内的多次请求合并成一次**；如果这一帧内已经有人同步调了 `render()`，排队中的那次会被取消。

**节点挂载走 `DocumentFragment`**：一次建好、一次插入。逐个 `appendChild` 等于把「插入」重复 N 遍（每插一次样式失效一遍），实测真 Chrome 里 `MutationObserver` 数到的一次 render 的 `#nodes` 变更批次从 **1 + 607 批降到 2 批**（1 次清空 + 1 次批量挂载）。

**「读测量」与「打角标」拆成两趟**：旧写法是「读 `offsetHeight` → 可能 `add class` → 下一个节点再读」，读写交替会让浏览器在每次 `add` 之后重新计算样式；拆开后读的那趟只读、写的那趟只写。

**拖拽 / 框选期间只动变换与选框**，抬手后才重排：平移 10 帧期间真 Chrome 里 `#nodes` 的 DOM 变更实测 **0 批**，`render()` 一次都没被调用，但 `viewport` 的 `transform` 确实在变。

**耗时自检**：每次渲染的真实耗时记在 `renderCost`、次数记在 `renderCount`，交给 📊 统计面板显示，大图慢渲染时顺带给出下一步建议 —— 让「卡不卡」从感觉变成可自查的数字。

**文件格式**：导出用的 Office / XMind 文件是**手写的 OOXML**：内置 ZIP 打包（store + CRC32）、docx / xlsx / pptx 的部件与关系、XMind 的 `content.json`。读取 `.xmind` 用的是**手写的 DEFLATE 解压器**（动态 / 静态哈夫曼），不依赖任何第三方库。

**OPML** 用浏览器原生 `DOMParser` 读写（`application/xml`），不自写 XML 解析器。关键细节是**属性值里的换行必须编码成 `&#10;`** —— 否则多行备注会被 XML 规范的「空白折叠」悄悄吃掉，导出去看着正常、导回来只剩一行。

**自动备份**基于 File System Access API：目录句柄存 IndexedDB，写入走 `createWritable()`，并做了节点数骤降保护。

**一致性设计**：

- **搜索**的三个开关（`Aa` / 全词 / 正则）不是三套各自为政的匹配代码，而是**一处 `findCompile()` 把「关键词 + 三个开关」编译成一个 `{test, replace}`**，搜索与替换共用同一口径。非法正则**降级为字面量匹配**并标红输入框，不抛异常、不卡死。
- **「仅导出选中分支」**没有去改 12 个导出函数，而是**导出期间临时把全局根换成选中子树的深拷贝**，导完复原 —— 对导出实现零侵入。
- **节点备注 / 标记 / 链接**在画布上只挂**绝对定位**的小角标，不参与 `offsetHeight / offsetWidth` 实测，所以加不加它们，tidy-tree 的列宽和坐标一个像素都不变（真 Chrome 里逐节点比对过）。
- **提示**统一走 `notify(kind, title, hint)` 一个入口（`info / ok / warn / err` 四级配色，第二行 `.th` 专门承载「怎么办」），不再是满地的 `toString` 字符串拼接。

**质量保障**：用 jsdom 真实加载页面跑端到端交互测试，**38 套、2850 条断言**；再用真实 Chrome headless 复核 jsdom 量不到的部分 —— 真实计算样式与排版、真实 `PointerEvent` 双指缩放并验算锚点、真实 `elementFromPoint` 命中（验证移动端抽屉没被遮罩吞掉）、真实读缩略图 canvas 像素、真的把 localStorage 写满 5 MB 验配额自救。导出的 docx / xlsx / pptx / xmind 用 Python `zipfile` 与 `python-pptx` 独立解包校验。

**反证**：每个修复都配一轮「反证」—— 临时把改动还原成旧行为，确认同一批用例**真的会变红**；否则说明测试没牙齿，先去补测试而不是改产品。现有 **23 份反证脚本**，跑完用 sha1 核对「还原回去的确实是原件」。另有 **21 组真 Chrome 探针**负责 jsdom 量不到的部分。一键回归：`python _test/runall.py`。
